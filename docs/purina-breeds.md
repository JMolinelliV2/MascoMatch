# Razas de Purina incorporadas en MascoMatch

Revisión: 2 de noviembre de 2026. Se recorrieron todas las páginas siguiendo el enlace a la página siguiente hasta la última: **18 páginas y 214 razas de perros; 5 páginas y 53 razas de gatos**.

Solo se incorporaron nombres de razas y variedades. Se retiraron prefijos editoriales como «Raza» o «Gato» y frases promocionales de los títulos para que las opciones sean claras. No se copiaron imágenes ni descripciones.

La lista se usa en todos los formularios de creación y edición, los reportes vinculados y el filtro de `/perdidos`. Se mantiene «Mestizo», las sugerencias anteriores que no se repiten y la posibilidad de escribir una raza libremente.
